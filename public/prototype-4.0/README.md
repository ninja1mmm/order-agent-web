# Supply Chain Agent Prototype 4.0

Prototype 4.0 explores a mail-scoped workflow without changing the production Next.js pages.

## Pages

- `00-intelligent-service.html`: pending work aggregated by mail.
- `01-task-workbench.html`: list view and customer timeline view in one workbench.
- `02-mail-parse-review.html`: mail-scoped source, material, date, quantity, preview, and merge flow.

Open `http://localhost:3001/prototype-4.0/index.html` from the existing Next.js development server.
